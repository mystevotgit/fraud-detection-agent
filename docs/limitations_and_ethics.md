# Limitations and Ethics

- False positives can inconvenience customers and delay legitimate transactions.
- False negatives can cause financial loss.
- Historical labels may contain investigation errors or reflect biased detection processes.
- Anomaly does not necessarily mean fraud.
- PCA-anonymized features reduce explainability.
- The dataset reflects a limited geography and time period and may not generalize to modern payment behavior.
- Blocking decisions should include human oversight, review, and appeal mechanisms.
- This project is an academic prototype and should not autonomously make real financial decisions.
